# 🍽️ Recipe Website

A simple and responsive **Recipe Website** built using **HTML, CSS, and JavaScript**. This project showcases different recipes with an attractive UI, making it easy for users to explore ingredients and cooking instructions.

---

## 🚀 Features

* 🧾 Browse multiple recipes
* 🔍 Search recipes (optional if implemented)
* 📱 Fully responsive design (mobile-friendly)
* 🎨 Clean and modern UI
* ⚡ Fast loading static website
* ❤️ Interactive elements using JavaScript

---

## 🛠️ Tech Stack

* **HTML5** – Structure of the website
* **CSS3** – Styling and layout
* **JavaScript (Vanilla JS)** – Interactivity

---

## 📂 Project Structure

```
recipe-website/
│
├── index.html          # Main homepage
├── style.css           # Styling file
├── script.js           # JavaScript functionality
├── images/             # Recipe images
└── README.md           # Project documentation
```
